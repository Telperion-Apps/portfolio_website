RouteShare

RouteShare is a competitive climbing companion built around sharing routes, challenging friends, and tracking group progress over time. The app combines social features with gym-specific route data so climbers can recommend climbs, run friendly competitions, and stay engaged between sessions.

Core Technologies

  • Flutter (Dart) - Cross-platform mobile app with custom UI, dialogs, and feature flows
  • Firebase Authentication - User sign-in and account management
  • Cloud Firestore - Real-time storage for friends, challenges, groups, and gym data
  • Firebase Cloud Functions - Server-side validation, scoring flows, and write protection
  • BLoC + Repository Pattern - Predictable state management and separation of UI from data logic
  • Firebase Cloud Messaging - Push notifications for friend requests, challenges, and groups

Supporting Technologies

  • Firebase Storage - Route photo uploads and cloud-hosted media
  • Firebase App Check - Additional protection for backend resources
  • Flutter Local Notifications - Device-side notification handling and navigation
  • Shared Preferences - Cached gym data and lightweight local persistence
  • GetIt - Service location for shared application services
  • Structured Logging - File-backed diagnostics and support workflows
  • Image Compression - Reduced upload payloads for challenge photos
  • Google Mobile Ads - Banner ad integration within the app shell
  • Git & GitHub - Source control and project management
  • Flutter Test + bloc_test - Unit coverage for core state logic

Features

Route Sharing

Climbers can recommend specific routes to friends with gym, grade, wall location, notes, and optional route photos.

Friend Network

Users connect through friend requests, manage accepted and pending relationships, and use a shareable friend code to grow their climbing network.

Competitive Challenges

Challenges can be sent to friends, accepted, and completed with scoring based on attempts, flash bonuses, and hint penalties.

Groups and Leaderboards

Players can create groups, invite friends, extend expiry windows, and compete on live leaderboards until the group winner is decided.

Gym Maps

Gym-specific SVG map support helps users identify route areas and visually place climbs inside the venue.

Smart Notifications

Push and local notifications route users directly into friends, challenges, or group screens when activity happens.

Expiring Activity

Challenges and groups have built-in expiry behaviour so shared content stays current and old competitions clean themselves up over time.

Support and Moderation Tools

The app includes feedback submission, user reporting, downloadable logs, account management, and privacy/terms flows for a more complete production-ready experience.
