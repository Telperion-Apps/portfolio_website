RouteShare

RouteShare is a Flutter mobile application designed for indoor climbers to share and complete climbing challenges with friends. With the help of real-world gym maps users can send route challenges, track completions, and compete through groups and leaderboards.

Core Technologies

  • Flutter (Dart) - Cross-platform mobile app with custom UI, dialogs, and feature flows
  • Firebase Authentication - User sign-in and account management
  • Cloud Firestore - Real-time storage for friends, challenges, groups, and gym data
  • Firebase Cloud Functions - Server-side validation, scoring flows, rate limiting and write protection
  • BLoC + Repository Pattern - Predictable state management and separation of UI from data logic
  • Firebase Cloud Messaging - Push notifications for friend requests, challenges, and groups

Supporting Technologies

  • Firebase Storage - Cloud storage for challenge photos and application logs
  • Firebase App Check - Additional protection for backend resources
  • Flutter Local Notifications - Device notification handling
  • Shared Preferences - Cached data and local persistence
  • GetIt - Used to manage and access shared services across the app
  • Structured Logging - Clear, organised logs to help diagnose issues and monitor the app
  • Image Compression - Reduced upload size for challenge photos
  • Google Mobile Ads - Ad integration
  • Git & GitHub - Source control and project management

Features

Send Challenges

Challenge friends to climb specific routes by selecting the gym, grade, style, location, and adding hints or optional photos.

Friend Network

Connect with other climbers using friend requests or a shareable friend code.

Complete Challenges

Track completed challenges and earn scores based on attempts, flash bonuses, and hint penalties.

Groups and Leaderboards

Create groups with friends, set an expiry time, and compete on a live leaderboard.

Gym Maps

Gym-specific SVG map support helps users identify route areas and visually place climbs inside the gym.

Smart Notifications

Push and local notifications keep users updated and take them directly to the relevant screen.

Expiring Activity

Challenges and groups have built-in expiry behaviour so shared content stays current and old competitions clean themselves up over time.

Support and Moderation Tools

Built-in tools for feedback, user reporting, downloadable logs, and account management.
