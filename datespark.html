DateSpark

Core Technologies

  • Flutter (Dart) - Cross-platform frontend for mobile, desktop, and web
  • Python - Backend application logic
  • Flask - REST API framework
  • PostgreSQL - Primary backend relational database
  • BLoC / Cubit - State management in Flutter
  • JWT Authentication - Secure access and refresh token authentication

Supporting Technologies

  • Flask-SQLAlchemy - ORM for relational database models
  • SQLite - Local/offline data storage on the client
  • Flask-Migrate - Database schema migrations
  • Flask Talisman - Adds HTTP security headers and enforces HTTPS
  • Flask CORS - Enables secure cross-origin API requests
  • Bcrypt / Flask-Bcrypt - Password hashing and credential security
  • Flask-Mail - Email verification and account workflows
  • GetIt - Dependency injection and service location
  • Google Mobile Ads - Rewarded ad integration
  • Docker & Docker Compose - Containerized local development
  • Pytest - Backend unit and integration testing
  • GitHub Actions - Continuous integration pipeline
  • Git & GitHub - Version control
  • Singleton Pattern - Shared service instances across the app

Features

Secure Authentication

User registration, login, email verification, and JWT-based session handling.

Date Discovery Wheel

A playful spin-to-discover experience that surfaces random date ideas with a game-inspired feel.

Token Reward System

Users spend tokens to spin and can earn more through rewarded ad interactions.

Timeline Scrapbook

A personal memory feed where users can save past dates and build their own story over time.

Photo and Memory Entries

Each timeline entry can include images, dates, and written notes for a richer record.

Account Management

Users can manage core profile details such as usernames, passwords, and stored session data.

Custom Themes

The app includes theme customization to let users personalize the experience.
